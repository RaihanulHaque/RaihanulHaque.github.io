# raihanulhaque.github.io

Personal site of Md Raihanul Haque Rahi, AI engineer. Live at https://raihanulhaque.github.io/

Plain HTML, CSS and JavaScript: no build step, no frameworks, no trackers.

- `index.html` — the page
- `assets/css/style.css` — styles, light and dark themes
- `assets/js/main.js` — particle field, Hishab replay, scroll effects
- `legacy/` — the 2022 versions of this site

To preview locally: `python3 -m http.server 8000` and open http://localhost:8000

01 About

I work on two ends of AI. One end is scale: chatbots, agents, and recommendation systems that real people use every day. The other is the edge: shrinking models until they run on a phone, with no server and no network.

I studied Mechatronics at RUET, which is why I care as much about the device a model runs on as the model itself. Most of what I build ends up measured: tokens per second, megabytes, exact-match scores.

Kiln

An on-device LLM runtime for Android and desktop.

One C API for chat, decision, embedding, speech-to-text, and text-to-speech models, with bindings for Flutter, Kotlin, Rust, and React Native. It detects hardware acceleration instead of assuming it, falls back to a plain Armv8 build on older phones, and reports what actually happened: which backend loaded, how much memory it took, and real tokens per second.

Hishab

A fine-tuned Qwen3.5-0.8B that turns English, Bangla, and Banglish messages into ledger entries on the phone, with no server. The latest build removes 4 of its 24 layers and heals the rest by distillation: 288 MB and 94.4% exact-match, with no measurable loss from the 343 MB model.

StereoLite

A stereo depth model with fewer than 3M parameters: over 10× smaller than DEFOM-Stereo, with 4× less VRAM. EPE 0.78 on SceneFlow, and it generalises zero-shot to real Middlebury scenes.

FaceVitals

Contactless heart rate, SpO₂, and blood pressure from an ordinary face video. Face landmarks pick the forehead and cheeks, then classic rPPG and TS-CAN read the pulse from tiny colour changes in the skin.

Krishok

A two-stage leaf-disease classifier for potato, rice, and tomato. One FasterNet-M backbone first picks the crop, then that crop's disease, at 99.5% end-to-end accuracy. Exported to ONNX and TFLite int8, it runs on Android.
